# Agent rules

Read `docs/PROJECT.md` and `docs/CHECKPOINT.md` before changing the project.

- The user approves product and technical decisions.
- Do not change scope or architecture without agreement.
- Keep changes minimal. Do not add contest features that are not in the current task.
- Do not commit secrets, `.env`, API keys, tokens, or credentials.
- Documentation must match the repository. Do not describe features that are not implemented.
- After a milestone, update `docs/CHECKPOINT.md`.
- Do not commit the raw Career Quest dataset or ZIP unless the user explicitly confirms that this is required.

There are no run or test commands yet. Functional code has not been created.

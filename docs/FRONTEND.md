# Career Quest frontend

## Статус

Реализован визуальный этап F1: общая оболочка и главная сотрудника для desktop
и mobile. Экран использует только синтетический демонстрационный профиль Марата
Есенова из `frontend/src/data/demoDashboard.js`.

Это не интеграция с backend:

- запросов к API, AI и базе данных нет;
- карьерный прогресс и рекомендация не рассчитываются в браузере;
- «Подробнее», «Отметить выполненным», «Путь» и «История» отключены до F2;
- структура fixture описывает только данные представления и не является
  проектом API-контракта.

Backend-код и серверные зависимости этапом F1 не изменены.

## Стек и структура

- React 19 + Vite 8;
- локально поставляемый variable-шрифт Inter;
- обычный CSS без UI-kit и библиотеки графиков;
- встроенные SVG-иконки без внешних запросов.

Основные файлы:

```text
frontend/src/App.jsx                     — экран и компоненты F1
frontend/src/App.css                     — desktop/mobile компоновка
frontend/src/components/Icons.jsx        — локальные контурные SVG-иконки
frontend/src/data/demoDashboard.js       — единый demo fixture
frontend/src/index.css                   — базовые токены и reset
```

PNG-референсы не копируются в приложение и не используются как фон или
содержимое страницы.

## Локальный запуск

Требуется Node.js версии, совместимой с Vite 8 (Node 20.19+ либо 22.12+).

```powershell
cd frontend
npm install
npm run dev -- --host 127.0.0.1
```

Vite выведет фактический локальный адрес, обычно `http://127.0.0.1:5173/`.

Проверки:

```powershell
cd frontend
npm run lint
npm run build
```

## Адаптивность и визуальная проверка

Основной desktop-режим включает боковую панель, верхний профиль и сетку 3:2.
До 1319 px используется компактная компоновка с нижней навигацией. На телефоне
карточки идут одной колонкой, а нижняя панель учитывает safe area.

F1 проверен в браузере при:

- 1586 × 992 px — основной desktop-референс;
- 390 × 853 px — основной mobile-референс;
- 360, 768 и 1440 px — отсутствие горизонтального переполнения и доступность
  элементов.

Локальные проверочные screenshots являются артефактами проверки и в Git не
коммитятся.

## Следующий этап

F2 выполняется только после независимой проверки F1. Он добавит вход,
объяснение рекомендации и согласованный демонстрационный результат выполнения.
Настоящие API-вызовы, серверная авторизация и изменение навыков относятся к
отдельно подтверждаемой интеграции.

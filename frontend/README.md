# Career Quest frontend

Визуальный этап F1: адаптивная главная сотрудника на React/Vite.

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

Проверки:

```powershell
npm run lint
npm run build
```

Экран использует только синтетический demo fixture и не обращается к backend.
Границы этапа, структура и будущая интеграция описаны в
[`../docs/FRONTEND.md`](../docs/FRONTEND.md).
